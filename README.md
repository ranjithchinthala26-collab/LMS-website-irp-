# IRP LMS Website Recreation

A responsive three-page front-end recreation of the IRP LMS assignment using HTML5 and CSS3.

## Files
- `index.html` — Home page and five-step learning journey
- `courses.html` — Nine embedded YouTube course tutorials
- `contact.html` — Contact information and message form
- `style.css` — Shared responsive styling

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish with GitHub Pages
1. Create a **public** GitHub repository.
2. Upload all four files to the repository root.
3. Open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. After deployment, open the published URL and test all three pages.

## Notes
- The supplied Cloudinary artwork and YouTube embed URLs are used as specified in the assignment.
- The Sign In control and contact form are visual front-end elements only; no authentication or backend form processing is included.
